# DECISIONS

1. **Стек:** выбран Python (WSGI) + SQLite, чтобы проект запускался локально без внешних зависимостей.
2. **Авторизация:** упрощена до выбора пользователя из сидов и хранения `userId` в cookie.
3. **Состояния заявки:** ограничены `CHECK`-констрейнтом в БД (`new | assigned | in_progress | done | canceled`).
4. **Защита от гонки:** переход `assigned -> in_progress` выполняется атомарным `UPDATE ... WHERE status='assigned'`.
5. **UI:** серверный HTML-рендеринг без SPA для прозрачной и быстрой реализации.
6. **Тестирование:** добавлены 2 автотеста (`unittest`) и отдельный `race_test.sh` для ручной проверки параллельных запросов.
7. **Запуск:** основной сценарий через `docker compose up`, альтернатива — запуск `python -m app.server`.
